# 每个镜头如何做到有参考

## 开始前回答三件事

先按 [镜头库](shot-library.md) 检索候选，将选中库 ID 与修订写入单镜 `library_reference`；再回答：

1. 这句口播要让观众看见什么对象、动作或关系？时间范围来自哪份已确认音频？
2. 哪条参考的哪个连续片段能承载这个任务？与前后镜的颜色、景别和节奏怎样衔接？
3. 参考里实际看见了什么，本片需要适配什么，还有什么尚未看清？

填写项目中的 [单镜模板](../assets/shot-review.template.json)。先覆盖全部给定参考再选择，不按轮换配额强塞每条参考，也不只循环使用自己熟悉的两三条。

选定前查项目的 `reference_usage`：参考区间、已用于哪一镜、显著素材/布局/动作组合、是否有意呼应。避免完整参考镜头仅换名词后又重复使用。可以复用同一参考片的不同方法，或为叙事呼应有意重复；不要为了去重强塞不适合口播的参考。

## 逐项映射

主参考负责整镜呈现方式；辅参考可补操作或转场。每个显著设计决定都应能指出证据，或明确标为内容适配。组合参考时核对光照、字形、空间与节奏是否相容。

| 维度 | 观察与记录 |
|---|---|
| 素材 | 主体做什么；真实细节、机位、景别、遮挡和动作；拿掉大字后是否还能说明任务 |
| 背景 | 冷暖、明暗分布、纹理颗粒尺度、反光与阴影，怎样和前景分开 |
| 构图与景深 | 主体与字的占比、负空间、前中后景、焦点、边缘失焦；同一行内部是否渐变失焦 |
| 字体与字幕 | 字形、字重、倾斜、字距、颜色、纹理、描边、阴影、位置和换行；普通字幕与重点字的区别 |
| 立体与人物覆盖 | 字面/侧面、厚度、光向、透视、阴影；文字与人物的前后关系、覆盖部位和程度、运动中的遮罩边缘 |
| 入场与建立 | 背景还是主体先出现；物件边界、投影、标题与正文是否先建立；方向、快慢、停留 |
| 运动与强调 | 相机、物件、字各自怎样动；先后、幅度、焦点；高亮范围与前一道标记是否保留 |
| 出场与衔接 | 硬切、遮挡、推进或横移等已观察方法；上镜末态与下镜首态怎样连接 |
| 声音 | 原声路线、实际听到的音效和触发点；未听音则标未验证 |

近似比例或帧数可以帮助判断，但不伪造精密测量，也不照搬参考固定时长。写“独立纸页上升 后建立标题 再大幅推近”，不要只写“高级纸张效果”。

## 静态样稿

交付正式质量关键画面与对应参考帧，同时检查整体观感和与前镜的关系。精确时间码回到原片核实，不仅依赖旧联系表或截取片段的标签。

生成提示词使用已看过的参考帧，写明保留哪些特征、替换哪些主体和文字、哪些认可部分不能改变。参考提供样式；本片文案、资料和事实独立负责。资料示意不能冒充真实论文证据。

按实际运动需求分离背景、物件、手部、纸张、标题、字幕和遮挡层，不为分层破坏已认可轮廓与光影。照片和材质用适合的图像工具，原生文字图形适合代码时保持可编辑。保存提示词、来源与版本。

交付实际可看可放大的画面，不用设计描述代替。当前镜有明显不同状态时可给两张关键帧，不擅自扩大到多个后续镜头。

## 动态实现

静态确认后回放参考连续片段，写出可检查的动作链：

`上镜末态 → 入口 → 建立 → 主动作或推近 → 强调或跟读 → 停留 → 下镜承接`

注明本片帧范围、口播触发、相机与物件变化、对应片段及目的。不要求每镜都有七段：参考硬切且稳定留字，就如实采用。不要为每个元素套同一种弹性曲线。

| 失败 | 缺失 | 修正 |
|---|---|---|
| 资料近景直接当开头 | 先看见独立资料再进入资料的过程 | 参考若有页边、投影和标题建立，补齐后再推进 |
| 全屏上擦代替纸页入场 | 背景、纸与空间被压成同一层 | 分开背景纸页，保留轮廓厚度与影子 |
| 每句都平移再扫同长黄条 | 强度、阅读关系和节奏重复 | 对照幅度、节奏、标记范围及去留 |
| 整行统一模糊 | 行内与周边的连续景深 | 焦点随相机变化，同时检查可读性 |
| 烘焙大字整图只能一起缩放 | 主体、相机、文字无法独立安排 | 保持认可样式并按需分层 |
| 呆板就加闪白震屏 | 素材、构图与动作问题未解决 | 先查建立、转折、景别和动作缺了什么 |

二维分层动作与视差可服务表达，但不能称为真实实拍动作。复杂翻页、运镜或动作超出当前方法时，说明具体局限并选择合适素材或工具。

## 交付前复检

- 按 [呈现还原与对照评审](reference-fidelity-review.md) 比较入口、建立、强调、退出阶段，再以原速播放当前镜，核对动作顺序和阅读时间；画面内容对应不等于呈现方式已还原。
- 连播相邻镜头与已完成段落，检查明暗、景别、声画重音、字幕、快慢和留白。
- 检查标题残影、透明边缘、重复手部、分层接缝、越界、闪帧、字幕碰撞和重叠人声。
- 保留已确认镜头，必要时比对关键帧或摘要；编译成功不等于美术通过。
- 给实际单镜及串联预览、时长和重点变化。用户要求评分、指出偏离参考或反复强调细节时，按对照评审逐镜记录评分与差距；普通交付给具体修正，不堆自评高分。
