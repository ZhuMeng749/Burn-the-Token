# 呈现还原与对照评审

用于每镜差异检查；开头、批量交付、反复返修或用户要求打分时进一步做成有证据的评审。评审对象是用户指定参考的呈现方式，不是 Agent 自己更喜欢哪种风格。

## 从对应阶段比较

1. 为本片镜头固定参考文件、连续区间及当前版本。按“入场、建立、主动作/强调、停留、出场”对齐实际存在的阶段；两片时长不同，不机械比较相同秒数或平均抽四张图。
2. 并排看相同展示尺寸的关键画面；文字边缘、厚度、遮罩、接缝在成片分辨率检查。再分别原速播放参考片段、本片片段和相邻镜头，不能只展示最漂亮的定帧。
3. 对每个显著差异记：`参考实际呈现 → 本片当前呈现 → 差异的画面证据 → 保留/修正理由 → 具体动作 → 复检结果`。有差距就写清，不以“已优化”“更高级”代替。

## 重点细节怎么查

| 项目 | 可比较的细节 | 常见错误 |
|---|---|---|
| 主体与构图 | 人物/物件/关键词的画面占比、裁切、位置、负空间与视线落点 | 只换了相同名词，大小和呈现关系却完全不同 |
| 立体文字 | 字形、倾斜、字面材质、挤出厚度相对字高、侧面明暗、透视、光向、接触/投射阴影 | 用一层描边或平移阴影充当参考的厚重立体字 |
| 人物与文字遮挡 | 谁在前、谁在后，覆盖哪个部位及范围，运动中覆盖如何变化，发丝/肩部边缘是否有光晕或漏底 | 因为怕遮挡，把参考中应压住人物的大字缩小或全移到旁边 |
| 纸张与物件 | 材质尺度、厚薄、折痕、边界、透视、投影、落位和惯性 | 物件变成无重量的平面卡片 |
| 景深与运动 | 清晰区、前后景、焦点转移、速度曲线、幅度、先后与停留 | 同类缩放、整层模糊或弹入代替原片不同的动作链 |
| 强调与装饰 | 横线、刷痕、边框、粒子是否在对应参考出现，出现时机和作用 | 为“丰富”给每个标题补横线/底条，掩盖主体层次不足 |

比例可由对照画面近似估计，记录“估计”与测量依据；无需伪造精密数值。人物局部覆盖可以是参考的重要手法，普通字幕仍需可读；两者不要混为一条“所有文字都不得覆盖人物”的规则。不得为了填表新增参考没有的效果。

## 有依据的评分

用户要求打分、指出偏离参考或反复强调细节时，给当前受影响范围逐镜评分并总结主要差距；普通交付可只给差异与修正。已有项目量表优先沿用，修前修后使用同一把尺，不靠换维度制造进步。

没有既定量表时可使用下表。每项用 0–5 分表示还原程度，再按权重换算：0 = 核心呈现缺失/方向错误；1–2 = 只有元素相似、关系差距大；3 = 动作与构图大体对应、关键细节仍弱；4 = 多数已观察细节接近、仍有局部差距；5 = 在实际观察范围内未发现重要偏差。此尺度为主观评审，不是客观相似度测量。

| 维度 | 权重 |
|---|---:|
| 主体素材、背景与表达关系 | 20 |
| 构图、景深、空间与遮挡 | 20 |
| 字体、材质、立体程度与可读性 | 20 |
| 入场、主动作、强调、停留与出场 | 20 |
| 声音动作对应与强弱节奏 | 10 |
| 相邻镜头及全段观感 | 10 |

- 每项保留参考与本片时间码、证据类型、差距、扣分理由和下一步。参考不自动被“客观评为满分”，它是本次呈现目标。
- 未看动态或未听音记 `NOT_RUN`；本次暂缓衔接设计记 `DEFERRED`；不适用项给理由。只报如“已检验部分 58/80，另 20 分未检验”，不补分、不换算成虚假的完整百分制总分。
- 无参考依据的显著装饰、关键动作缺失、错误立体/遮挡关系、非预期重复、缺字/露底/叠音等实质问题单列。不能用平均分抵消问题并标为通过。
- 总结先指出最影响观感的具体问题与修复优先级；同一轮修正后回到同一动作阶段复检，不要求每轮分数都上升。

## 开头联合检查

“提高留存”转成可检查的设计：主体和冲突是否及时建立，第一眼能否读懂重点，信息变化是否跟随口播，重点字停留是否足够，声音是否抓住对应动作且有主次。按参考观察决定快慢和强弱，不预设必须几秒一变、不靠持续震屏或大音量填满开头。

把开头三镜作为一个短段连播，同时逐镜比较参考；大字占比、人物覆盖、注意力接续与音效触发一起调整。保留此前版本，可切换试听时保持同样的人声增益和播放音量。未获得真实观看数据，只能说针对开场表达做了调整，不能声称已经提高留存率。

## 批量质量

交付一批或一次做完剩余镜头时，每镜仍有参考与阶段对照；已发现的问题在交付前修正或如实标为未完成。用复用组件提高效率，但不能把不同参考全部压成“静态底图＋标题＋横线＋同一个入场”。先看各镜，再串联听看强弱和重复；联系表、代码通过、渲染成功都不能代替这一步。
