# 逐镜工作流与继续规则

## 恢复与模式

先按 SKILL.md 判断本次是仅入库、直接从已有库制作，还是入库后制作。仅入库执行 [镜头库工作流](shot-library.md) 并交付实际记录；以下阶段用于视频制作。恢复项目 `library.root` 和选中镜头的 ID/修订，不要求重新上传现有参考。

读取项目的 `project-state.json`，记录素材指纹、文稿、声音、规格、当前镜头、交付版本、用户原话及确认范围。静态确认、动态确认、衔接确认、整段确认与导出授权是不同事实。历史记录帮助定位，当前文件与播放结果才证明实现情况。

默认 `review_mode: shot_by_shot`：先完成当前一镜的参考对照和静态样稿，确认后完成动态及衔接，再逐镜推进。全片文案、时间轴、参考索引可以先规划；规划不等于已经制作。

明确整段授权优先：用户要求先做一段、约三分之一、直接做完或沿用已通过模板时，记录 `review_mode: batch_preview` 与范围。在授权段内仍逐镜对标和自检，不插入用户未要求的逐镜批准。约三分之一只是可选范围；旧项目已有工作模式和授权不被新版 Skill 重置。

“接着做下面三个”按已完成镜头顺序推进三个，记录 `batch_size: 3`；“后面的一起做”扩大剩余交付范围，保留原质量标准、镜头记录与逐镜对照。批次数量属于当前授权，不把三镜或一次做完固化为所有项目默认。

同时恢复 `continuity.mode`：`preserve` 保留现有衔接；`reference_first` 优先逐镜还原，暂缓额外衔接设计；`optimize` 在指定范围改善整体连贯性。无明确要求时保留现状，新项目按参考建立切点。采用最近的明确指令并记录作用范围，不因历史上要求连贯就持续重做后续所有转场。暂缓设计仍需检查非预期闪帧、露底、声画错位等缺陷。

## 默认逐镜循环

| 阶段 | 本阶段完成 | 接下来 |
|---|---|---|
| reference_analysis | 全部参考的覆盖记录、整体规律、当前镜候选片段 | 对齐本片内容 |
| waiting_media / timeline_locked | 缺媒体则记录估时；媒体齐则锁实际口播、音轨与帧范围 | 做当前镜映射 |
| shot_static_preview | 对应参考、正式质量静态样稿与简明对照 | 根据视觉反馈修正，认可后做动态 |
| shot_motion_preview | 单镜动态、含前镜的衔接、原速播放检查 | 根据反馈修正，认可后下一镜 |
| batch_preview | 授权范围内逐镜完成且串联复看 | 按指定范围继续 |
| full_preview | 全片连续观感、声音、字幕和段落强弱复查 | 满足确认及导出授权后输出 |
| ready_to_export / exported | 获批版本渲染并验证实际媒体 | 交付文件 |

先做出可供判断的结果，不能在授权范围内只交计划再问能否开始。每轮明确是静态、动态预览还是导出文件。

## 如何解释简短反馈

- 静态对照页之后的“好的”：结合逐镜流程，视为该静态稿通过并继续其动态，不重复请求许可。
- 动态之后的“好的 接着下一个镜头”：确认刚交付范围，制作下一镜的参考映射与静态稿。
- 已约定逐镜推进时，动态之后仅“好的”也可按约定继续；若只是审阅评论，不扩大为全片或导出授权。
- “素材可以”只确认素材，不自动确认动效、声音或整片。用户批评入场时，保留认可材质，重做运动结构。
- “先给思路 看后再生成”改变当前停点：先完成有参考证据的方案；随后“去做吧”就是执行授权。
- “后面全部做完”授权剩余预览，不重复逐镜问；“完整预览没问题 导出吧”同时确认预览和导出。
- 在当前预览后的“导出来吧高清的”是对当前交付版本的导出指令，按原片规格或已约定高清规格执行，不再索要同义确认。若随后要求先改音效，完成修改再沿用该导出授权；不要把新音效自动登记为已经试听认可。
- “除了第 X、Y 镜其他都改”将 X、Y 的当前版本列入 `protected_ranges`，只修改其余指定范围。“某处回老版”恢复该边界或镜头对应旧版，记录帧范围及版本，不回滚无关改进。
- “连贯先不用管，按参考做”仅暂缓额外衔接设计；“不一定放大缩小”要求依据具体动作、形状、视线、声音或语义选择衔接，不是换一个全片通用转场。
- 确认只对应用户看到的版本。实质修改影响哪些部分，只让哪些部分重新审看，不推翻无关镜头。

## 执行边界

沿用正常声音、原文、实际时长与拍摄规格。缺最终人声仍可做视觉稿，但不能声称字幕与动作已精确对齐。不为套参考节奏偷偷加速声音、改词或挤掉句尾。

缺素材或工具时继续无依赖工作并记录缺口；不把未播放称为已观看，不重复未知状态的付费提交。默认预览期不导出视频；用户明确改变交付方式时遵从授权。

状态中保留实际 URL、Composition、完成帧范围、素材路径和下一步。各镜确认后仍需连播相邻镜头及完整段落，防止逐镜都像参考、拼起来却节奏雷同。

修改前保存可恢复版本。批量修改后比对保留范围的时间轴、素材和关键画面；用户另有全片音量等横跨范围的要求时，按该要求更新相关维度并说明，视觉保留不自动禁止已授权声音调整。
