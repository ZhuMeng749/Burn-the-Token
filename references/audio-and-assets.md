# 精确声音时间轴、素材与音效

## 先探测再对齐

对真人原片、最终音频、克隆音、B-roll 实际探测：时长、流、旋转后显示尺寸、fps 分数、时间基、音频采样率/声道、源入点。可用 ffprobe 或现有媒体工具；保存探测结果。检测段首尾黑屏/留白，确认是用户分隔标记还是正文，不能把分隔黑屏直接当成片镜头。

将获批人声转录并按词/短句对齐；人工听核每个真人/克隆音切点、专有名词、数字和章节停顿。通过台词、波形、源 timecode 与口型确定真人源入点，不能把“同一句”视为两次录制时长完全一致。

若有最终人声母带，使用其内容顺序与时间位置作为基准，真人段仍优先原片人声。以母带为坐标不等于全程叠播母带。若原片与母带在剪辑或语速上不匹配，记录偏差；可根据源入出点匹配时先剪辑，无法匹配则说明最小选项，不能擅改已锁定声音。

无合并母带但各段最终音频已齐，可按既定顺序构建内部人声时间轴。真正的人声空白作为有意停顿记录；不得自动把所有空白压缩掉。最终画面、字幕、音效跟随这条实际时间轴。

## 唯一人声路线

| 区间 | 原视频内嵌音 | 最终母带对应区间 | 独立克隆音 |
|---|---|---|---|
| 真人段（默认） | 开，正确 trim/gain | 关闭同一句人声 | 关 |
| 克隆音段使用母带 | 真人视频无关/静音 | 开 | 关，不能再叠一条 |
| 克隆音段使用独立片段 | 关 | 关 | 开 |
| 用户明确指定全程最终母带 | 真人视频静音 | 开 | 关 |

四条要点：

1. 视频播放组件可能自带音频；画面静音后用单独抽出的原声播放也可，但路由只能保留一个。
2. `timeline.json` 列出所有实际启用的人声区间，包括内嵌音。母带拆成启用区间，不能用一条全片 master 加一条原声再寄望后期音量盖住。
3. 交叉淡化优先放在无语音余量，避免两句人声重叠；清理点击声不能切掉辅音/尾音。对话确需交叠时要单独设计并明确标记，不使用本技能默认独白检查规则掩盖它。
4. B-roll 默认去掉非必要原声；确需机器/环境声时另记 ambience，不让素材旁白或隐藏音乐进入混音。已含 BGM/SFX 的母带不能再整条叠加同类背景，先检查或取得可用分轨。

试听真人与克隆音切换的音色、响度和底噪；统一可感知响度，保留情绪动态，重点字可突出但不能削波。最终 LUFS/true peak 按交付平台或用户目标设置并测量，不把历史案例某个值当全平台硬指标。

## 四类素材与语义映射

| 类型 | 用途 | 选择与标注 |
|---|---|---|
| 官方真实资料 | 支撑确实发生的事实、数据、产品 | 第一手来源、许可状态、内容片段、日期；重构证据页但不改数据含义 |
| B-roll | 具象呈现口播中的对象和动作 | 精确实体、动作、镜头方向、时长、使用权；通用示意不得冒充特定事件现场 |
| AI 生成素材 | 难以取得的非证据情境/隐喻 | 记录提示词与生成结果，标“示意”；不得伪造官方截图、实验结果、人物证据 |
| Remotion 自绘 | 关系、流程、时间压缩、比较、因果、数量变化 | 数值和语义来自脚本证据，几何/文字由代码生成；按讲解逐步长出 |

素材清单字段：asset_id、type、script_ids、spoken_entity、visual_action、evidence_or_illustration、source_url、rights_status、local_path、width/height/fps/duration、source_in/out、crop_plan、scene_ids、motion_role、fallback、status。

官方素材也须确认实际使用条件；无法使用则换来源或自绘事实图，不抠除水印/署名来假装自有。清理浏览器框架只裁导航和网址等非内容区，不能删掉必要数据注释；许可要求的署名可用机构/作者名或说明文档承载，若与画面禁区冲突则换素材。

逐条检查“说什么→出现什么”：说机械臂不能用显微镜顶替，说某家厂商不能用无关设备当该公司证据。每张素材必须实际存在并可解码；下载任务 ID、网页缩略图或生成提示词不算交付素材。

## 用户音效库

用户本轮指定路径优先，其次沿用项目中已指定且可读的库，再定位当前用户桌面 `音效`。递归列出可读音频，结合名称筛选、探测时长并实际试听候选；按动作选择，不只看文件名猜。外接盘缺失时明确报告路径不可读，继续无依赖工作，不能静默换库后声称已调用指定库。不复制整个库进技能包，只将本片必要文件按原许可纳入项目。

| 动作 | 候选声音家族 | 对齐方式 |
|---|---|---|
| 纸张出现/擦过/翻页 | Paper / Page / Rustle | 对齐接触、翻折或遮挡峰值 |
| 字/刻度/数字变化 | Tick / Digital Click | 对齐信息触发，不每个字都响 |
| 贴纸/标签弹入 | Pop | 对齐落稳或弹性峰值 |
| 手绘线/下划线 | Scribble | 覆盖绘制区间，结束干净 |
| 同向推入/穿越 | Directional Whoosh / Deep Sweep | 对齐速度峰值，按运动方向声像 |
| 章节或结论落点 | Low Hit / Impact | 对齐大字落下，先让 BGM 留空间 |
| 实体空间 | Ambience | 建立环境，低于人声，不强行铺满 |
| 手机消息/界面反馈 | Notification / UI Click | 对齐真实出现的提示或操作，区分轻触与通知 |
| 齿轮/开关/实体运动 | Mechanical / Gear / Switch | 对齐机械接触、启动或落位，不能全替换成翻页声 |
| 真实键盘操作 | Keyboard | 跟随可见操作区间，避免持续打字声遮口播 |

先写声音的职责，再挑候选：动作拟音、信息反馈、强调重音、转场、环境层。按画面材质、速度、重量、方向和时长筛选同类变体，试听其瞬态、音高、尾音及与口播的关系；不要为多样性把不相关的声音硬塞进来。手绘/下划线声音只有实际绘制动作才使用。文件起点不一定是峰值，听后结合波形裁切和对齐，记录淡入淡出、声像及源处理。

cue sheet 至少记录：event_id、动作/shot_id、声音职责/家族、库内源路径、源片段、项目内路径、动作帧与声音瞬态、源处理增益、轨道增益、pan、fade、试听状态、选择理由。按全片顺序查同一文件及同类音色是否机械重复；重复可以是有意呼应，需符合画面。文件数、声音家族数、音效条数都不是质量指标，不规定凑满多少种，不必每次微动都响。

不能主观听音时可完成文件可读性、波形、瞬态、增益和同步的技术检查，但试听与音色选择结论保留 `NOT_RUN`；不能把页面点击播放、无削波或参考文件存在称为已听过或听感通过。

## 开头的画面与声音一起编排

用户要求增强开头时，按已选参考的动作与口播设计主重音、次提示、材质声和留白。主重音服务最重要的入场/结论，轻提示服务后续信息；需要时先收再落，避免每一下都同样响。具体是否使用低频撞击、掠过、键盘或纸声由当前画面决定，不把某次成功组合变成所有视频开头模板。

先连播开头三镜，再放回全片核对能量变化；后文不要处处复制开场的强重音。对照旧版与参考时保持本片人声增益和播放器音量一致，防止把“更响”误当作更合适。减少重复要同时检查声音家族、音高、尾音、密度、声像和强弱，不只替换文件名。

## 轨道增益与实际混音

优先读取项目 `audio_preferences` 及用户最新范围。如果用户尚未指定，可将人声 -3 至 -6 dB、常规效果 -8 至 -12 dB 作为调整起点，再按源响度和实际听感确认；它们是轨道 dB 增益，不是平台统一的 LUFS 目标或成片峰值。Remotion 线性音量按 `10 ** (dB / 20)` 转换，例如 -6 dB 约为 0.501，而不是把 -6 直接填入 volume。

源音频响度不同，同样轨道增益不等于同样听感。必要的源校准、滤波与包络单独记录，不通过隐藏增益抵消用户约定。常规效果、重点效果和人声分开控制；声音叠加后重新测混音峰值/真峰值及所需响度，并试听口播密集段与强音效处。技术测量、声画同步、主观听感分别记录，任何一项通过都不能代替另外两项。

更新源组件、cue sheet、实际混音与预览音轨后核对一致；已经有导出授权的，再确认最终 MP4 包含的是最新混音，而非仅预览页换了声音。

## BGM 的段落包络

按钩子/解释/故事/数据高潮/失败转折/结论标能量曲线。允许一首音乐通过剪辑与音量包络分段，不强制每章换歌。参考音乐只分析节奏，不擅取原曲使用。

章节可用“duck→约 0.2–0.5 秒呼吸空间→impact→下一段建立”作为候选，依实际停顿与参考观察调整。高潮前先收，信息密集时降，观点落下后留一点余韵；不用持续大声掩盖发音或路由问题。
