# 视觉语言与运动设计

## 总原则

先以对应参考为审美依据，再把本片对象、动作与关系放进去。逐项映射见 [shot-by-shot.md](shot-by-shot.md)。状态变化、稳定停留、留白与微运动以参考和口播为依据，不固定凑 2–3 次，也不让整片都只做静态图的小幅平移。

先从 [个人镜头库](shot-library.md) 与当前项目的参考范围匹配表达任务。具体字形、比例、动作与停留回到相应原片时间码核对，不能将旧项目偏好当作新片默认风格。

不要用无对应参考的 PPT、SaaS 卡片模板、规整四宫格、静态资料长停和无关赛博 HUD 替代所需镜头。统一来自字体层级、配色、材质和运动逻辑，不来自每镜复制同一布局。一个语义段有清晰主视觉。

## 口播到画面的设计表

| 口播信息 | 原创视觉动作 | 普通字幕的职责 |
|---|---|---|
| 物体/设备 | 使用正确真实素材或自绘实体进入，与讲述动作一致 | 提供完整语义兜底 |
| A 与 B 的关系 | 两实体出现，再长出连接/排斥/约束/反馈 | 不代替连线与动作 |
| 数量/时长变化 | 先见旧状态，再压缩/累积/比较，最后结果稳定 | 保持单位与限定条件 |
| 因果/失败修正 | 显示触发→响应→反馈→修正，逐步揭示 | 标核心概念，避免全屏段落 |
| 官方证据 | 先定位资料，再推近事实、highlight，移动到下一处 | 简洁归纳，不把网址上屏 |

能画出来不等于事事做繁复图表。解释目的越简单，动作越应精确；真实 B-roll、资料阅读、自绘演示、真人回场交替承载不同任务。

## 资料是被镜头阅读的

按对应参考还原阅读路径。常见路径是全貌定位→进入关键词或数据→高亮→移向相关证据→退出，但不能把常见路径当作所有资料镜头的模板。阅读时留足停留，不让字无法看清；运动中持续裁掉网站框架。清理后的内容页可重新编排，但数字、图例、上下文不能被改得失真。

纸张、便签、档案有轻透视、投影、边缘厚度、细纹理和适度叠层；便签像贴上去，纸张像有惯性地滑过，档案像翻阅。避免全部悬浮在圆角 UI 容器里。材质是载体，不是无关装饰。

## 信息随口播逐步出现

镜头建立对象后，随着关键词出现关系、标签、数字或高亮，再把注意力移向结论。一个 8 秒解释段可有“实体建立→关系变化→结果定格”，持续微运动贯穿；时间以真实口播对齐，不写死 8 秒模板。

每镜写清注意力与运动载体，幅度、速度和落点从对应参考观察，再按口播、安全裁切和可读性适配。参考明确大幅推进时，不用 2% 的轻微缩放代替；参考稳定停留时，不强加微动。普通字幕保持稳定。

## 字幕、关键词与真人

- 普通字幕简洁、稳定、有对比，按语义分行；不每字弹跳、不遮嘴/眼和当前证据。
- 强调词采用对应参考已出现且适合本片的字形、材质、显隐和强调方式；不因工具能做就新增盖章、弹字或结果牌，同一段不过多争抢视线。
- 章节大标题与 BGM duck→impact 配合，标题强动效与普通字幕拉开层级；motion blur 用于快速运动，不把字糊到不可读。
- 真人保留拍摄构图和语气。贴图、资料与关键词按对应参考的空间关系适配，不机械照搬左右位置。大字位于人物前后或覆盖肩身时，按参考核对覆盖程度，不能一概缩小移到空白处；文字厚度、透视、明暗及遮罩边缘见 [细节评审](reference-fidelity-review.md)。普通字幕保持可读，不擅自改横竖比或强裁头肩。

## 转场运动交接

先读项目 `continuity.mode` 及最新作用范围，遵循 [工作流](workflow.md)。获准优化时，记录上镜出口与下镜入口的方向、速度、焦点及语义关系，选择实际适合的连续线索。普通 hard cut 也可凭动作、视线或语义实现连贯，不要求每次都添加动效；参考本来硬切或用户要求保留旧切点时保留。连播后的整体舒适度是判断依据，不能把每镜独立 enter/exit 拼接当作完成衔接。

| 手法 | 交接方式 | 常见失败 |
|---|---|---|
| push-through | 上镜推向对象/关键词，下一镜接其内部空间或主体 | 推近后停住再重新飞入 |
| match cut | 形状、位置、动作或尺寸相呼应 | 只因颜色相同就接无关对象 |
| paper wipe | 纸张滑过并遮满切点，带同向动势显露下一镜 | 纸边未遮住，底下突然跳图 |
| foreground occlusion | 前景物体遮住切点，下一场同向揭开 | 遮挡、镜头与声音不同步 |
| motion blur | 对快速移动统一模糊并接住速度 | 用模糊掩饰所有断裂或糊住文字 |

切点前/中/后逐帧看，再实际连播。禁止把互不相干的 enter/exit 动画首尾相拼就宣称“丝滑”。

## 画面禁区与质量边界

URL、域名、地址栏、第三方网站导航、页脚、搜索框在所有帧都禁止出现，包括截图内容边缘、视频内嵌字、转场缩放露出的外圈。优先取干净内容区域；必要时重做准确证据页，不能仅用小模糊遮挡后继续露出导航结构。审计来源仍保留在文件。

严格依据参考的字形、材质、主体占比、光影与动作逻辑制作；内容和素材替换为本片所需，不默认搬用原片文案、人物、声音或镜头。没有参考依据的装饰、角标、配色和效果不自行增加。相同元素不等于相同质量，仍要整体复看。

## 视觉设计提示词

> 以实际观察的对应参考为基准，将本片口播映射为主体、动作和关系。逐项核对背景、构图、字体、景深、入场、建立、主动作和衔接，保留参考的层级与节奏，记录内容适配。检查整镜和相邻镜头观感，遵守已确认原声、规格与画面约束。
