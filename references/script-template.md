# 原创选题与真人/克隆音脚本模板

## 原创改造

把参考压缩成“观众的问题→认知缺口→证据推进→转折→观点兑现”的逻辑地图，然后为新主题重建。结构按参考实际论证调整，不机械套这五格。至少改变切入问题、论证/案例组织和关键视觉隐喻，使用自己检索的证据与用户经历；不能只替换人名、品牌和数字。

无主题时列三个角度：受众痛点、原创主张、可核实证据、可视化机会与预计时长；选一个直接写完。有主题则服从主题；已有获批稿则跳过选题重写，仅做分段/标注。没有事实支持的角度换题，不杜撰统计、实验、引语或“我亲测”。

对现实人物、产品能力、数字、日期等查原始资料，记录来源和适用范围。来源 URL 只保留在制作文档。用自己的表达解释事实，不摘抄参考台词，不模仿其标志性口头禅或暗示是原作者作品。

## original-script.md

```text
主题 / 目标观众 / 目标时长 / 暂定假设
原创主张：这条片让观众理解什么
叙事节拍：每段任务、转折与兑现

[P01] 完整可读口播……
[P02] 完整可读口播……

事实核对：论点 → 第一手来源 → 限定条件 → 已核实/需删除/需弱化
原创差异：选题角度、证据组织、例子、结论与参考的区别
估时方法 / 文案版本 / 用户已确认范围
```

估时要包含停顿；中文、英文、数字的朗读速度不同。拿到真实人声后以实际为准，不把估计秒数当剪辑入点。

## performance-script.md

### 顺序总表

| 顺序 | segment_id | script_ids | 类型 | 文件建议名 | 段落任务 | 估时/实测 | 情绪、重音、停顿 | 专有名词 |
|---|---|---|---|---|---|---|---|---|

真人适合钩子、重要观点、转折和结尾，克隆音适合解释、案例、数据，但以用户已录段落为准。不要固定为历史案例的 5 段真人/6 段克隆音，不额外要求重拍。

### 每个真人段

```text
ID：P01 / 文件：P01_开场.mp4
【拍摄提示】视线、表情、字幕安全区、段前后余量
【表演标注】[情绪:好奇] [重音:关键名词] [停顿:0.4s]
【完整台词】只包含实际要念的话
【不可擅改】获批用词、数字、观点
```

### 每个克隆音段

```text
ID：V01 / 文件：V01_概念解释.wav
【执行标注】声线/服务（已指定才填写）、情绪、语速、停顿与重音
【纯 TTS 输入】只保留要朗读的内容，不让模型读出“明显停顿”等说明
【后期停顿】原句之后需留白的语义锚点及建议时长
```

服务支持 SSML 或停顿控制才按其实际语法传入；不把未经支持的标签混进正文。没有服务/音色则仍交付纯文本。用户已给最终配音则不重复生成；已指定声线不可擅换。分段生成便于只修错的那一段，不为每段强制生成多版而产生额外费用。

### 发音表

| 写法/字幕 | 读法 | 全称或缩写 | 数字/单位的口播展开 | 已试听 | 修正方案 |
|---|---|---|---|---|---|

专有名词使用可靠读法，无法确定则标记，必要时请用户给念法；不得把不确定音译当事实。可以单独补录专名，但保留文字意义。字幕使用正确写法，不能为修发音把错别字带入画面。

### 录制交接

列出真正缺少的文件、段落及顺序；建议纯人声 WAV、原始真人视频保留原音。需最终人声母带时注明不提前混入 BGM/SFX。收到已混音母带时先检查现状，不要求无意义重交。

## 写作提示词

> 根据参考的抽象叙事方法和我自己的主题/受众，写一篇完整原创口播。用可核实的新证据重建论证，不替换参考名词伪装原创。为每段分配真人或克隆音，分别输出可直接录制台词与纯 TTS 文本；情绪、停顿、重音、专名读法单列。已有确认稿保持原文；缺少真人与音频时交付录制包，不虚构精确时间轴。
