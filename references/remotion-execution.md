# Remotion 执行规范

## 进入项目

读取适用的 AGENTS.md、现有 package.json、锁文件、Composition 注册与入口、素材组织。优先延续原项目、版本和已有可用组件，不顺手重构无关文件或升级依赖。不存在项目才按当前可用的 Remotion 创建技能建立；可调用能力不存在时读 Remotion 官方文档，不编造工具。

按当前任务读取可用的 Remotion 创建/markup/字幕/Studio/渲染说明；这些是条件依赖，不是此技能必须安装的固定插件 ID。声音、图像和转录服务同理。运行时路径从环境发现，不把作者电脑的缓存路径写入项目。

## 数据与画面分离

以 production 数据和可复用组件驱动视频，建议按职责拆分：

```text
src/
  index.ts / Root.tsx              实际入口与 Composition
  compositions/OriginalVideo.tsx  组装场景与声音
  scenes/                         真人、资料、解释、章节、案例
  components/                     字幕、关键词、纸张、图解、运动交接
  data/                           经核实的时间轴、素材和声音 cue
public/media/                     本片实际使用的媒体
production/<视频标识>/            报告、版本、确认、探测与检查记录
```

已有项目不同布局时无需改目录。组件不是完成证据：它必须被正确注册、挂入目标 Composition、放到实际时间轴，并在预览中播放到目标片段。

## 精确时间轴与动画

- Composition 使用探测/获批的宽、高、fps 与实际 durationInFrames；预览播放器缩放不改这些参数。
- 从秒到帧统一转换并处理半开区间，Sequence 的局部时间与全片时间明确区分；trim、字幕、音量包络使用同一基准。
- 保持输入原速；用户另有要求才改 speed，并同步调整素材时长与声音。
- 动画由帧驱动，使用当前版本支持的插值/弹性函数；随机纹理要确定性，不用墙上时钟、未固定随机数或不可复现 CSS 动画驱动关键动作。
- 字幕根据实际音频而非文案平均分配。已有 SRT/词级转录先解析核验，不用脆弱的硬编码行切分。
- 媒体使用项目可解析的路径；网页截图/外链素材先取得可用本地文件，避免最终渲染依赖临时签名链接。加载字体与媒体须可验证，禁止漏字/字体 fallback 悄悄改变排版。
- 音乐与 SFX 独立控制音量；真人和母带按音轨表互斥。运行结构检查后，核对实际组件静音设置是否与 manifest 相同。

## 预览策略

按照 [workflow.md](workflow.md) 中已有模式和授权范围实现。默认当前一镜：静态认可后做单镜动态和含前镜的串联 Composition。明确授权整段时在该段逐镜实现与自检，不增加逐镜批准。说明本次实际完成帧范围与时长；全片计划不冒充已完成。

先尝试复用已运行且属于该项目的 Studio。否则使用项目本地可用 CLI/脚本启动且不自动打开系统浏览器；典型形式是项目支持的 `remotion studio <实际入口> --no-open`。启动命令必须与已安装版本和真实入口一致；不要猜端口或把旧案例 localhost 地址当当前路由。

读取启动日志并验证服务，再用可用浏览器打开真实 Composition，检查画面和音频实际播放。浏览器无法检查时标“服务已启动，播放未验证”，不得声称用户已可正常看到成片。

允许用低分辨率代理改善 Studio 流畅度，但保持原 Composition 参数，明确原片/代理映射、裁切与同步一致；导出路径必须指向原始质量文件。原片丢失时不能静默用代理当最终源。

预览期不输出 MP4、WebM 或 GIF，包括以“测试渲染”名义导出短视频。可以抽静帧/联系表及检查音频数据做质检；这不替代连续播放。逐镜、整段与导出的确认范围见 workflow.md；已有明确交付授权优先。

## preview-and-changes.md 模板

```text
阶段 / version / 实际完成范围 / 全片计划时长
项目绝对路径 / 入口 / Composition ID
规格：width × height、fps 精确值、durationInFrames
本机实际 URL / 启动方法 / 浏览器播放验证状态
原始媒体与代理映射 / 人声路线
本次修改：文件 → 目的 → 影响时间段
检查：画面、声音、切点、禁区、缺素材
用户确认：原话、日期、对应版本与范围（没有则写尚未确认）
下一步：等当前静态或动态反馈 / 按授权制作下一镜或整段 / 等全片确认与导出指令 / 可导出
```

localhost 只能用于本机预览，不能作为已公开分享的链接。修改说明中区分已运行、已观看和未检查的项目。

## 获批后导出

确认输出对应最新获批版本，使用原始质量素材与匹配项目版本的渲染方法。导出参数按用户规格，渲染进度完成后仍检查真实容器、像素尺寸、fps、时长、音轨以及视频/音频完整解码。抽查首尾、所有章节、真人切点、资料推近/转场最大边界；再核音乐与人声听感。

若帧率、色彩或编码限制必须改变主规格，先说明可用方案，不能拿未告知的转换结果交付。只在质量清单标明的范围内声称验证通过。

## 执行提示词

> 基于已锁定文稿、人声时间轴、素材清单和视觉规范，在现有 Remotion 项目中实现当前授权范围。保持用户原拍摄规格，保证真人原声和母带不重叠，使用实际音效文件，所有可视化与口播对齐。默认交付当前镜正式质量的静态与动态对照，实际播放单镜和串联效果，再逐镜推进；若用户已授权整段则完成授权段。给真实路由、完成范围和修改说明，符合完整预览与导出授权后再输出成片。
